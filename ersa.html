PROJ-03 · INDEPENDENT BUILD

ERSA — Enterprise Release Stability Agent

A LangChain-based agentic AI tool that supports release governance decisioning — bringing faster, data-backed risk assessment into a discipline traditionally run on spreadsheets and manual sign-offs.

Built by Sujoy G.
Framework LangChain
Status Primary AI proof point in job applications
01Why I built it

Release governance — deciding whether a change is safe to deploy, what the blast radius looks like, and who needs to sign off — is a discipline that, even in mature organizations, often still runs on spreadsheets, tribal knowledge, and manual judgment calls under time pressure.

ERSA was my attempt to bring some of that decisioning onto a more structured, data-backed footing — an agentic tool that can reason over release-related data and support the kind of risk assessment that release managers do today largely by memory and gut feel.

02What it does
  • Consolidates release-relevant data from multiple sources rather than relying on a single system of record — including Jira, alongside other tooling such as ServiceNow.
  • Applies agentic reasoning to surface release risk signals that would otherwise need to be pieced together manually across tools.
  • Aims to support — not replace — the judgment calls a release manager makes at go/no-go gates, by giving them a faster, more consistent starting point.
